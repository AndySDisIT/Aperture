# Gig Optimizer MVP

## Supabase schema
Run the SQL in `supabase/schema.sql` in your Supabase SQL editor.

## Environment
Copy `.env.example` to `.env` and fill in values.

## Run locally
```bash
flutter pub get
flutter run
```

## Project structure
```
lib/
  app.dart
  main.dart
  models/
  screens/
  services/
  state/
  widgets/
```
